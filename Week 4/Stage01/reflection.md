I was given a simple SmartCare appointment program in Python. The program used a list to store appointments and functions to book and display them. Then I tested the program with different inputs, including a normal appointment, a blank patient name, a double booking and a None value. From the testing it was found that the code would allow for double bookings and only checked if the patient name was empty. I then changed it so it didn't allow for double booking. The ai version of the code used a function that created one appointment and returned it as a dictionary. Comparing it to the Human code you are able to see why using a list would be more beneficial when needing to store more appointments. The Ai however assumed that only one appointment would need to be made at a time and did not include a list that would store multiple appointments. Overall the Ai code did help me understand the code better and i was able to grasp more into why a list of dictionaries is more flexible than seperate variables.
